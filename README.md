# asm-examples

Larger example programs for [asm-editor](https://github.com/Specy/asm-editor), the web IDE for assembly. Each folder is one example, the source of an archive the editor ships among its examples, with its own README and license.

| Example | What it is | License |
| --- | --- | --- |
| [asmOS](asmOS/) | A small operating system in C and assembly: processes, a compositing window manager and eighteen applications, DOOM, Pac-Man and a RISC-V Assembly Editor among them | GPL-2.0-or-later |
