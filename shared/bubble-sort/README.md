# Bubble sort

This program sorts an array from smallest to largest. It uses bubble sort, and sorts in place: the sorted array replaces the original in the same memory. Look at the array in the memory panel to see the result.

| Target | What it sorts |
| ------ | ------------- |
| M68K   | Eight signed words, at `numbers`. |
| MIPS   | Eight words, at `numbers`. |
| RISC-V | Eight words, at `numbers`. |
| X86    | Six signed qwords, at `values`. |
| Z80    | Eight unsigned bytes, at `numbers`. |

Go to the course's lecture to read a line-by-line explanation: [M68K](https://asm-editor.specy.app/learn/courses/m68k/examples/bubble-sort), [MIPS](https://asm-editor.specy.app/learn/courses/mips/examples/bubble-sort), [RISC-V](https://asm-editor.specy.app/learn/courses/risc-v/examples/bubble-sort), [X86](https://asm-editor.specy.app/learn/courses/x86/examples/bubble-sort) or [Z80](https://asm-editor.specy.app/learn/courses/z80/examples/bubble-sort).
