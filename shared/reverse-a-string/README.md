# Reverse a string

This program reverses the zero-terminated string at `text` in place, without a second copy. It uses two pointers that start at the two ends of the string and move towards the middle, swapping the bytes they point to.

Look at `text` in the memory panel to see the reversed string. For example, `Assembly` becomes `ylbmessA`.

Go to the course's lecture to read a line-by-line explanation: [M68K](https://asm-editor.specy.app/learn/courses/m68k/examples/reverse-a-string), [MIPS](https://asm-editor.specy.app/learn/courses/mips/examples/reverse-a-string), [RISC-V](https://asm-editor.specy.app/learn/courses/risc-v/examples/reverse-a-string), [X86](https://asm-editor.specy.app/learn/courses/x86/examples/reverse-a-string) or [Z80](https://asm-editor.specy.app/learn/courses/z80/examples/reverse-a-string).
