# Reverse a string

Reverses the zero-terminated string at `text` in place, with no second copy. Build, Run, and look at `text` in the memory panel: `Assembly` becomes `ylbmessA`, or `assembly` becomes `ylbmessa` on X86.

Two pointers start at opposite ends of the string and move towards each other, swapping the bytes they point at until they meet.

The editor's courses explain it line by line: [M68K](https://asm-editor.specy.app/learn/courses/m68k/examples/reverse-a-string), [MIPS](https://asm-editor.specy.app/learn/courses/mips/examples/reverse-a-string), [RISC-V](https://asm-editor.specy.app/learn/courses/risc-v/examples/reverse-a-string), [X86](https://asm-editor.specy.app/learn/courses/x86/examples/reverse-a-string) and [Z80](https://asm-editor.specy.app/learn/courses/z80/examples/reverse-a-string).
