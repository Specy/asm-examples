# Number to string

This program converts a number to text in hexadecimal, decimal and binary, and prints it to the console. It finds the digits by dividing by the base, without any service that prints numbers.

| Target | Console output, in order |
| ------ | ------------------------ |
| M68K, MIPS, RISC-V, Z80 | `BEEF`, `48879`, `1011111011101111`: the value 48879 in base 16, 10 and 2. |
| X86 | `12345`, `3039`, `11000000111001`: the value 12345 in base 10, 16 and 2. |

Go to the course's lecture to read a line-by-line explanation: [M68K](https://asm-editor.specy.app/learn/courses/m68k/examples/number-to-string), [MIPS](https://asm-editor.specy.app/learn/courses/mips/examples/number-to-string), [RISC-V](https://asm-editor.specy.app/learn/courses/risc-v/examples/number-to-string), [X86](https://asm-editor.specy.app/learn/courses/x86/examples/number-to-string) or [Z80](https://asm-editor.specy.app/learn/courses/z80/examples/number-to-string).
